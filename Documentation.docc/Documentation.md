# ``Yomu``

Read manga in an iOS app that feels like home.

## Overview

Yomu leverages the modern features of SwiftUI, SwiftData, and Swift 6 concurrency to bring you manga quickly and efficiently in a safe manner.

Unlike like a normal documentation catalog this will be more of a collection of my thoughts and experiences building this application. While most types, objects, and functions will have some basic standard documentation views and logic will have additional explanations.
